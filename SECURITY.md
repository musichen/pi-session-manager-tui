# Security Policy

## Reporting a vulnerability

Open a GitHub issue in this repository for non-sensitive reports. For a sensitive vulnerability, contact the maintainer privately first through the GitHub profile at https://github.com/musichen instead of posting details publicly.

## Notes

Session files under `~/.pi/agent/sessions/` contain your pi transcripts. Do not attach real session files, transcripts, or screenshots of private conversations to issues. When reporting a bug, reproduce it with a throwaway session instead.
